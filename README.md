# Password Generator

A clean, customizable password generator with real-time strength indicators and one-click copy functionality.

## Features

- Toggle uppercase, lowercase, numbers, and symbols
- Adjustable password length (1-64 characters)
- Real-time strength indicator (Weak/Good/Strong/Excellent)
- Generates two unique passwords at once
- Click to copy passwords to clipboard
- Fully responsive design

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/yourusername/password-generator.git
```

2. Open `index.html` in your browser

That's it! No dependencies needed.

## Usage

1. Toggle character types using the switches
2. Enter desired password length
3. Click "Generate passwords"
4. Click any password to copy it
